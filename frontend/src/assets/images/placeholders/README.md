# Asset Type Placeholder Images

This directory contains default placeholder images for each asset type.

## Image Specifications

- Format: SVG (scalable vector graphics)
- Size: Optimized for 300x300px display
- Style: Editorial Geometry design system compliant
- Colors: Using design tokens from the application

## Asset Types

The following placeholder images are available:

1. **server.svg** - Server assets
2. **workstation.svg** - Workstation assets
3. **network_device.svg** - Network device assets
4. **storage_device.svg** - Storage device assets
5. **software_license.svg** - Software license assets
6. **peripheral.svg** - Peripheral assets
7. **keyboard.svg** - Keyboard assets
8. **mouse.svg** - Mouse assets
9. **laptop.svg** - Laptop assets
10. **monitor.svg** - Monitor assets
11. **headset.svg** - Headset assets
12. **laptop_charger.svg** - Laptop charger assets
13. **hdmi_cable.svg** - HDMI cable assets
14. **network_cable.svg** - Network cable assets
15. **access_card.svg** - Access card assets
16. **default.svg** - Default fallback image

## Usage

These images are used when an asset doesn't have a custom uploaded image.
The image upload component automatically selects the appropriate placeholder based on the asset type.
